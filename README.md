# 鉴微 · AI 风险研判与修复决策助手（可交互 Demo）

面向 ToB 安全运营的**漏洞风险研判与修复决策**平台原型：AI 自动初判漏洞、给出可复核的依据与修复方向，并按角色驱动派发与闭环。

本 Demo 为**单文件 HTML**，双击即可打开，也可直接由 GitHub Pages 托管，无需构建、无外部依赖。

## 在线访问

GitHub Pages：`https://<用户名>.github.io/<仓库名>/`

## 演示账号

密码统一 `demo123`，共 8 个账号 / 4 类角色（差异化的可见范围是本 Demo 的讲解重点）。

| 账号 | 角色 | 视角 |
| --- | --- | --- |
| `tester` | 研判员 | AI 研判产出：结论与依据、决策台账、派发工单 |
| `zhang` / `chen` / `li` / `wang` / `zhao` | 研发责任人 | 处置负荷：名下工单、修复方向、漏洞解读 |
| `admin_p05` | 管理员 | 全平台态势：资产、决策台账、留痕、用户角色 |
| `auditor_01` | 审计员 | 核查可信度：归档箱、报告、操作留痕、异常行为预警 |

登录后可用任一角色走查；首屏引导提供「一键体验」自动演示路径。

## 主要模块

| 模块 | 说明 |
| --- | --- |
| 漏洞研判 | AI 初判 +  Agent 编排过程（意图理解 → 工具调用 → 结果校验），结论带可追溯依据 |
| 修复决策 | 修复方案定稿与派发，pending / confirmed / rejected 状态流转 |
| 工单中心 | 闭环流转：待处理 → 处置中 → 复检 → 闭环，含 SLA 时效判定 |
| 平台对话助手 | 自然语言提问，答案带来源标识，且受当前角色可见范围约束 |
| 操作留痕 | 全量操作的只追加日志 + 链式哈希校验，可导出 CSV |
| 异常行为预警 | 基于操作留痕与登录日志按账号建行为基线，偏离标红；中高危自动推送告警给管理员与审计员 |

## 数据说明

站内全部数据为**本地模拟种子数据**，刷新页面即恢复初始状态；不含任何真实客户资产或漏洞信息。
